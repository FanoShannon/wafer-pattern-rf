# 方法与评估协议

所有模型输出图像级模式标签和树投票概率估计。它们不提供逐 pattern mask，手工特征也没有把混合图还原成各自图案。评估单位是一张 wafer map。

## 特征

### 基础 168 维

`spatial_features` 从原始二维 `0/1/2` map 提取：

| 内容 | 维度 |
|---|---:|
| 全局失效密度、有效面积比例、网格宽高关系 | 3 |
| 径向密度分布 | 12 |
| 角向密度分布 | 16 |
| 4×4 与 8×8 空间网格 | 80 |
| 横纵方向密度分布 | 32 |
| 失效点位置、协方差及半径统计 | 15 |
| 原始与膨胀后连通域统计 | 10 |
| 合计 | 168 |

区域密度的分母使用该区域有效 die 数量。外部空白不当作通过电测的 die；全局有效面积比例是单独的几何描述。

### 扩展 502 维

`advanced_features` 前 168 维与基础版本完全一致，再增加：

| 特征块 | 维度 | 用途 |
|---|---:|---|
| 径向×角向联合密度 | 224 | 保留靠近晶圆边缘的位置与角度之间的关联 |
| 多方向条带投影 | 54 | 18 个方向的背景标准化峰值、超额集中程度、熵 |
| 多尺度局部密度 | 24 | 3、5、9 网格窗口下的密度及超额统计 |
| 连通域位置与形状 | 32 | 原始失效点及局部高密区域中两个最大连通域的面积、中心、伸长和边界统计 |
| 新增合计 | 334 | 与原特征拼接后为 502 维 |

条带投影受 Radon 思路启发，但不是连续 Radon 变换、拟合直线或骨架重建。连通域的细长程度来自协方差矩，不代表已准确定位 Scratch。特征函数不接收标签或 split，也不修改输入 map。

## RF 与解码

基础配置使用 scikit-learn `RandomForestClassifier`：300 棵树、`min_samples_leaf=2`、`max_features='sqrt'`、主种子 42。单标签任务使用 `balanced_subsample`；多标签任务使用多输出二元目标，不设置类别权重。

单标签任务排除包含两个以上模式的图，类别为正常加八种单模式。预测取最大概率类。

多标签任务覆盖正常、单模式及混合图，每个基础模式一维。基础训练命令在验证集上独立选择每类 F1 阈值：0.1 到 0.9、步长 0.025；同分选最接近 0.5 的阈值。同时报告固定 0.5 的结果。树投票概率没有经过专门的生产域概率校准。

增强/特征消融全部固定 **0.5**，不在各实验臂上另外调阈值，避免将阈值变化当成增强收益。三次训练种子固定为 `42, 20261114, 812`。

## 训练集增强

所有父图和合法组合词表只来自 train。组合生成器遇到 val/test 记录会拒绝执行。只生成训练中已存在的 29 种双/三/四模式组合，不强行创造发行版不存在的 Random 或 Near-full 混合类型。

主实验每种组合增加 100 张，共 2,900 张，并匹配以下三臂的数量和标签组合分布：

1. **D4 对照**：重采样真实混合训练图，再旋转或镜像。它改变训练权重，不能视为新增独立晶圆。
2. **naive_union**：不同单模式父图经 D4 变换后，在有效晶圆交集内对原始失效点取并集。该控制故意保留多份源背景累加的影响。
3. **structured_mix**：对父图使用相同的无标签软结构规则，结合 3×3 局部密度和五点多方向线支持，概率性保留源失效点；合并后补一次共享背景噪声。默认背景率由正常训练图的失效密度中位数估计，本次为约 0.07472。

每张父图变换只使用 90 度旋转和镜像，不插值或平移。默认晶圆交集保留每个父图至少 90% 的有效 die；每个采样 signal 至少保留 3 个独占 die，独占比例至少 5%，否则拒绝候选。独占支持检查针对启发式 signal，不能证明真实物理模式没有被掩盖。

软规则有非零采样下限并加入方向支持，以减少直接平滑抹去细线的风险；但 signal 不是像素真值。它仍可能保留噪声或丢失结构。审计输出记录父 ID、组、D4 变换、共享晶圆比例、signal 保留率、独占比例、拒绝原因和人工 QA 所需数组。

一轮生成数量及尝试预算都低于 4,000。输出按 D4 去重，拒绝直接复制已知原始训练图或生成图填充配额；不足时报告真实 shortfall。合成图继承训练父图依赖关系，始终留在训练臂。

## 选择与留出

候选为 168/502 维×无增强/D4/直接并集/结构组合八组。按验证集 mixed-only 整组正确率选择，再比较 Micro F1；继续同分则优先较少特征/样本。选择记录先写入，再评估新的 580 张 mixed-only 留出集，只比较基础方案和选中方案。

旧 capped test 已被先前实验查看，其所有消融结果标为探索性。新留出集固定后不根据其表现重新挑特征、增强、阈值或随机种子。生成训练图与留出图也检查 D4 交叉。

补充的 single-only 对照不使用原混合训练图的像素，但合法组合词表来自混合训练标签，因此不能称为完全没有混合监督或未知组合零样本泛化。

## 指标

- **Accuracy**：单标签任务的正确分类比例。
- **Exact match / 整组正确率**：一张图的八个标签全部正确才计正确。
- **Micro F1**：汇总全部样本及标签的 TP/FP/FN 后计算。
- **Macro F1**：逐标签 F1 的平均。mixed-only 中 Near-full/Random 没有正例，因此另报仅对有支持标签平均的 `macro_f1_over_labels_present`；两种定义不能混用。
- **配对区间**：在相同 fresh 样本上按图 bootstrap 计算差值；它未建模未知 GAN 父样本相关性，不能解释为真实产线保证。
